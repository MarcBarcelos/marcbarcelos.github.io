# marcbarcelos.github.io

Personal academic website of Marc Alexander Barcelos, PhD Fellow at TEXT: Center for Contemporary Cultures of Text, Aarhus University.

Live at **https://marcbarcelos.github.io/**

Built with [Hugo](https://gohugo.io/) (minimal custom layouts, no theme) and deployed to GitHub Pages by GitHub Actions on every push to `main`. See [UPDATING.md](UPDATING.md) for how to edit content.

| What | Where |
|---|---|
| Bio, supervisors, affiliations, interests | `content/_index.md` |
| Name, title, tagline, email, social links | `hugo.yaml` (`params`) |
| Research framework and projects | `data/research.yaml` |
| Papers | `data/papers.yaml` |
| Talks / News / Teaching / Awards | `data/talks.yaml`, `data/news.yaml`, `data/teaching.yaml`, `data/awards.yaml` |
| Education and experience | `data/background.yaml` |
| CV, PDFs | `static/files/` |
| Photo | `static/images/photo.jpg` |
| Styles (colours and fonts at the top) | `assets/css/style.css` |

Preview locally: `hugo server`, then open http://localhost:1313/.
